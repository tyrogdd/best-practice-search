# 检索工具清单模板

复制此模板为当前 Agent 环境定制一份持久配置。`信源标识` 使用 [信源目录](../sources.md) 中的 slug；启动参数、密钥和 MCP 授权存放在各运行环境自身的配置中，本清单只记录**路由入口、降级条件与访问边界**（不要混入单次具体任务的调研日志）。

- **运行环境**：<Agent / 客户端名称、核心可用能力（Search / Fetch / CLI / Browser / MCP）>
- **访问范围**：<仅公开互联网 / 含用户已登录浏览器会话 / 含指定私人连接器>
- **可用 CLI / API 工具**：<如 `gh`、`curl`、`yt-dlp`、专用 MCP 名称>

| 信源标识或任务 | 默认入口与能力 | 备用入口与降级/交接条件 | 已知限制 |
| --- | --- | --- | --- |
| `<slug>` | 能完成搜索、原文读回、评论或媒体检查的实际工具 | 失败或受限时的降级入口，以及何时交接用户登录或第三方采集 | 如需登录、人机验证、仅可读简介等 |

使用方式：
1. 将填好的清单与 [跨平台检索编排 Skill](../../SKILL.md) 配套提供给当前环境。
2. 首次接入新工具时，用一条只读查询验证其能否返回原始链接/ID 及完整正文，再投入正式调研。
3. 若环境只能处理本地文件，填写可读材料路径及跨方采集交接约定即可。
